## 这是什么

景渊完整运行在你自己的电脑上。它抓取真实的 A 股行情、财务指标与新闻，所有数字由本地工具库算出，
再把这些数字交给大模型去**叙述**——而不是让模型去**编造**。

它记得你之前聊过什么，学习你常看的股票，自动把你生成的研究报告沉淀为个人知识库——全部存在本机，永不上传。

它是研究工具，不是交易工具。不接入任何券商，也永远不会。

> **景渊** — 景，远望；渊，深潭。看得远，也看得深。

## 代码里落到执行点的三条铁律

这不是文档里的口号。每一条都有对应的执行点和测试。

| 铁律 | 具体是什么意思 |
| --- | --- |
| **数字零幻觉** | 报告里每个数字都来自本地工具算出的结构化事实块。数据源取不到，字段就渲染成 `—（未获取）`，绝不写成 `0.0`。 |
| **可溯源** | 每份报告写明数据来自哪个源、哪几段是模型写的、哪几段降级成了规则模板。引用的新闻标题原样呈现。 |
| **仅供参考** | 模型被禁止使用买卖指令性动词。产出会自检+清洗，命中禁词会替换或降级为模板。每份报告强制带免责声明。 |

## 功能

### 专业对话（带记忆）

用简称提问（"茅台现在多少钱"），智能体识别标的、按需调用工具——实时行情、财务、新闻、技术指标、
行业估值——每项都带数据时点引用。可以一次比较多个标的，也能跨轮追问。

智能体**记得你的历史对话和研究报告**。问"我之前跟你说过我看好什么板块？"，它会检索本地记忆来回答。
上传自己的文档（txt / md / pdf / docx）成为个人知识库，对话中智能体可自动检索引用。

### 行情分析（含大盘概览）

行情页顶部展示**五大指数实时看板**（上证指数 / 深证成指 / 创业板指 / 科创50 / 沪深300），点击任一
指数卡片切换到该指数的走势视图。支持全 A 股搜索、1 分钟分时、日 K、成交量、五档盘口及 MACD/RSI/KDJ/BOLL。

### 研究任务——连续流式

智能体编排结构化报告，工具调用轨迹实时可见。全篇**从摘要到结尾一次 LLM 调用连续流式输出**——
一个字一个字写下来，摘要与正文之间没有停顿。

模板覆盖**个股深度**、**行业研究**、**财报点评**、**风险评估**。篇幅由**思考档位**（low / medium / high / max）决定。

### 报告自动入知识库

每份生成的报告自动分块嵌入本地向量数据库（rag.db）。对话中模型通过两级检索调用历史报告：
`search_memory` 返回索引卡（带引用号），`read_memory` 深读完整原文。

### 报告库

报告落本地 SQLite，支持导出 Word / PDF / TXT / Markdown。真删除时报告正文、研究任务、
Agent 检查点**及向量块**一并清除。

### 知识库（用户文档）

上传你的研究文档（txt / md / pdf / docx，≤20 MB）。自动解析、分块、嵌入向量库，
对话中智能体可检索引用。你的文档永不出本机。

### 模型配置——15+ 家厂商

预置 15 家 OpenAI 兼容厂商（8 家国内、7 家国外）。自带 Base URL，模型清单实时拉取。
API Key **加密存储**（机器绑定）。

### 可选语义嵌入

五家厂商提供向量模型（通义千问 / 智谱 / 豆包 / OpenAI / Gemini）。在设置页配置一家即可
将记忆检索从关键词匹配升级为真正的语义搜索。不配置则使用本地离线嵌入，开箱即用。

## 架构

```
┌──────────────────────── 你的电脑（Windows）─────────────────────────┐
│                                                                    │
│  Electron 外壳 —— 无边框窗口，应用内标题栏                          │
│        │  加载 http://127.0.0.1:<端口>/                            │
│        ▼                                                           │
│  FastAPI 后端（PyInstaller sidecar，同源托管前端）                  │
│    • 父智能体（编排）→ 场景子智能体                                 │
│      （market-analysis / fundamentals-synthesis）                   │
│    • deepagents / LangChain / LangGraph，SQLite 检查点              │
│    • 行情源：腾讯 → 新浪 → 东财 → AkShare 兜底                      │
│    • SQLite：finresearch.db（对话、报告、设置）                     │
│    • 向量库：rag.db（sqlite-vec，本地 RAG）                        │
│    • 记忆生命周期：90 天自动归档，向量定期清理                        │
│        │                                                           │
│        │  HTTPS —— 唯一的出网点                                     │
│        ▼                                                           │
│  云端 LLM API —— 你的密钥，你选的厂商                               │
└────────────────────────────────────────────────────────────────────┘
```

你的提问、文档和生成的报告永远不出本机。唯一携带你 API Key 的请求，只发往你自己选定的模型厂商。

## 安装

从 [**最新 Release**](https://github.com/lryoooow/Financial-AI-Agent-Platform-/releases/latest) 下载：

| 文件 | 用途 |
| --- | --- |
| `JingYuan-Setup-2.7.0.exe` | 安装包，会创建开始菜单与桌面快捷方式 |
| `JingYuan-Portable-2.7.0.exe` | 便携版，免安装直接运行 |

Windows 10/11 x64。无需另装 Python 或 Node，运行时已全部打包在内。

安装包未做代码签名，首次运行 SmartScreen 会拦截。选择**更多信息 → 仍要运行**。

## 首次运行

1. 启动景渊，后端自动拉起。
2. 进入**模型配置**，选一家厂商，粘贴 API Key，选定模型。
3. 点击**设为当前推理模型**。
4. 回到对话提问，或去**研究任务**生成第一份报告。

没有 Key 也能用：行情、图表、知识库、数据源诊断照常工作，只是模型撰写的段落由规则模板代替。

## 数据存在哪

全部位于 `%APPDATA%\FinResearch\`：

| 文件 / 目录 | 存什么 |
| --- | --- |
| `finresearch.db` | 对话、报告、任务、设置、加密的 API Key、用户画像 |
| `rag.db` | 向量数据库（sqlite-vec）：记忆块、报告块、知识库块 |
| `kb/` | 你上传的原始文档副本 |
| `archive/conversations/` | 超 90 天对话的压缩归档原文 |
| `context/` | 对话图片等媒体 |
| `assets/images/` | 图片资产（服务端已降采样） |

**数据生命周期**：对话闲置 90 天后自动摘要（LLM 生成 ≤300 字）、原文压缩归档、删除行级消息。
报告与知识库块永久保留。对话向量块 180 天清理。删除报告时 DB 行、任务、检查点**及向量块**一并清除。

想彻底重置，关掉软件删掉这个文件夹即可；想备份，复制走即可。

API Key **加密存储**（机器绑定加密）。仅会被发往你选定的模型厂商。
