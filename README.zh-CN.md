## 这是什么

景渊完整运行在你自己的电脑上。它抓取真实的 A 股行情、财务指标与新闻，所有数字由本地工具库算出，
再把这些数字交给大模型去**叙述**——而不是让模型去**编造**。

它是研究工具，不是交易工具。不接入任何券商，也永远不会。

> **景渊** — 景，远望；渊，深潭。看得远，也看得深。

## 代码里落到执行点的三条铁律

这不是文档里的口号。每一条都有对应的执行点和测试。

| 铁律 | 具体是什么意思 |
| --- | --- |
| **数字零幻觉** | 报告里每个数字都来自本地工具算出的结构化事实块。数据源取不到，字段就渲染成 `—（未获取）`，绝不写成 `0.0`。10 日均线算不出来就不提它，而不是拿相邻均线插值伪造。 |
| **可溯源** | 每份报告写明数据来自哪个源、哪几段是模型写的、哪几段降级成了规则模板。引用的新闻标题原样呈现，绝不改写。 |
| **仅供参考** | 模型被禁止使用买卖指令性动词（买入/卖出/加仓/减仓/止损…）。产出会做自检，命中则重写一次，仍命中就回退模板。每份报告强制带免责声明。 |

行情快照取数失败时，报告会如实说明并省略所有由价格派生的数字——而不是悄悄印出一行「PE 0.0 倍」。

## 功能

**专业对话** — 用简称提问（"茅台现在多少钱"、"宁德时代最近怎么样"），景渊会识别标的、拉取实时行情
与近期资讯，作为带数据时点的事实块注入上下文。简称有歧义时（"平安" 指中国平安还是平安银行？）它会
反问，而不是猜。取不到数据时它直说取不到，不会凭记忆报一个过期价格。

**研究任务** — 确定性的 LangGraph 管线产出结构化报告：

```
标的归一化 → 基本面研究 → 行情与技术 → 投资摘要 → 报告生成
```

四种模板各自组装不同的栏目：**个股深度**、**行业研究**、**财报点评**、**风险评估**。
没有数据支撑的栏目不会被写出来，而是如实标注「数据不足，本报告不展开」。

**报告库** — 报告落本地 SQLite，支持导出 Word / PDF / TXT / Markdown。

**模型配置** — 预置 15 家 OpenAI 兼容厂商（8 家国内、7 家国外），自带 Base URL。
填入你自己的 API Key，模型清单可从各厂商 `/v1/models` 实时拉取。

## 架构

```
┌──────────────────────── 你的电脑（Windows）─────────────────────────┐
│                                                                    │
│  Electron 外壳 —— 无边框窗口，应用内标题栏                          │
│        │  加载 http://127.0.0.1:<端口>/                            │
│        ▼                                                           │
│  FastAPI 后端（PyInstaller sidecar，同源托管前端）                  │
│    • LangGraph 固定管线，SQLite 检查点                             │
│    • 行情源：东财直连 → 新浪 → 腾讯 → AkShare 兜底                  │
│    • SQLite：对话、报告、设置                                       │
│        │                                                           │
│        │  HTTPS —— 唯一的出网点                                     │
│        ▼                                                           │
│  云端 LLM API —— 你的密钥，你选的厂商                               │
└────────────────────────────────────────────────────────────────────┘
```

你的提问、持仓和生成的报告永远不出本机。行情数据取自公开接口。
唯一携带你 API Key 的请求，只发往你自己选定的模型厂商。

## 安装

从 [**最新 Release**](https://github.com/lryoooow/Financial-AI-Agent-Platform-/releases/latest) 下载：

| 文件 | 用途 |
| --- | --- |
| `JingYuan-Setup-1.2.2.exe` | 安装包，会创建开始菜单与桌面快捷方式 |
| `JingYuan-Portable-1.2.2.exe` | 便携版，免安装直接运行 |

Windows 10/11 x64。无需另装 Python 或 Node，运行时已全部打包在内。

安装包未做代码签名，首次运行 SmartScreen 会拦截。信任来源的话，选择
**更多信息 → 仍要运行**。

## 首次运行

1. 启动景渊，后端会自动拉起，窗口停在**专业对话**页。
2. 进入**模型配置**，选一家厂商，粘贴你的 API Key，选定模型。
3. 点击**设为当前推理模型**。
4. 回到对话，或去**研究任务**生成第一份报告。

没有 Key 也能用：行情、图表、数据源诊断照常工作，只是模型撰写的段落会由规则模板代替。

## 数据存在哪

全部位于 `%APPDATA%\FinResearch\`：

- `finresearch.db` —— 对话、报告、模型配置、用户画像
- `backend.log` —— 后端日志
- `port.txt` —— 后端实际绑定的本地端口

想彻底重置，关掉软件删掉这个文件夹即可；想备份，复制走即可。

API Key 以明文存放在这个本地数据库中，仅会被发往你选定的模型厂商。
