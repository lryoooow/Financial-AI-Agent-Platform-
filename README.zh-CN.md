## 这是什么

景渊完整运行在你自己的电脑上。它抓取真实的 A 股行情、财务指标与新闻，所有数字由本地工具库算出，
再把这些数字交给大模型去**分析与叙述**——而不是让模型去**编造**。

它是研究工具，不是交易工具。不接入任何券商，也永远不会。

> **景渊** — 景，远望；渊，深潭。看得远，也看得深。

## 代码里落到执行点的三条铁律

这不是文档里的口号。每一条都有对应的执行点和自动化测试守护。

| 铁律 | 具体是什么意思 |
| --- | --- |
| **数字零幻觉** | 报告里每个数字都来自本地工具算出的结构化事实块。数据源取不到，字段就渲染成 `—`（未获取），绝不写成 `0.0`。均线窗口不足就不连线，绝不拿相邻均线插值伪造。 |
| **可溯源** | 每份报告写明数据来自哪个源、数据时点、哪几段由模型撰写、哪几段降级为规则模板。引用的新闻标题原样呈现，绝不改写。 |
| **仅供参考** | 模型被禁止输出面向读者的买卖指令性表述（建议买入/卖出/加仓/止损…）。产出经合规守卫自检，违规自动重写或回退模板，每份报告强制附带免责声明。 |

行情快照取数失败或估值缺失时，报告如实标注并显示 `—`——而不是悄悄印出一行「PE 0.0」。

## 核心工作台

- **深度研究（独立任务台）** — 侧栏首位独立工作台。选定标的（支持股票代码、中文简称、拼音首字母联想如 `gzmt` → 贵州茅台，或直接输入「半导体」「光伏」等申万行业）与研究模板（**个股深度** / **行业研究** / **财报点评** / **风险评估**），可附加你重点关注的具体问题。智能体自动并发取数，**从投资摘要到各分析章节一次性逐字真流式写出**，思考过程与工具轨迹实时可见，支持中途取消、后台运行与一键追问。
- **投研问答（多轮问股 · 看图解盘）** — 用自然语言提问（"茅台现在多少钱"、"茅台和五粮液对比一下"），智能体按需调用实时行情、财务报表、新闻、技术指标、行业估值与本地知识库工具，支持粘贴走势截图多模态解盘与长对话上下文自动压缩。
- **实时行情与图表速读** — 分时走势、日 K 线（MA5/10/20 与完整开高低收悬浮窗）、五档买卖盘口、技术指标（MACD / RSI / KDJ / BOLL），支持盘中自动刷新与图表悬停 AI 速读。
- **报告库与本地知识库（RAG）** — 所有生成的研报自动持久化至本地 SQLite 并切分入本地 FTS5 知识库，跨会话对话可自动检索历史研究结论（带报告日期溯源）。支持一键导出 **Word (`.docx`) / PDF / HTML / Markdown / TXT**，支持彻底物理删除（报告、关联任务、知识库切片与检查点一并清除）。
- **设置中心与个性化学习** — 预置 15+ 家国内外 OpenAI 兼容模型厂商及自定义中转端点，支持从厂商 `/v1/models` 实时拉取模型列表与思考深度分档（默认 / 低 / 中 / 高）；可选开启用户画像偏好学习、上下文窗口治理、系统托盘后台驻留与开机静默自启。

## 架构

```
┌──────────────────────── 你的电脑（Windows）─────────────────────────┐
│                                                                    │
│  Electron 外壳 —— 无边框窗口、应用内标题栏、系统托盘后台驻留          │
│        │  加载 http://127.0.0.1:<端口>/                            │
│        ▼                                                           │
│  FastAPI 后端（PyInstaller sidecar，同源托管前端）                  │
│    • deepagents 智能体（LangChain/LangGraph），SQLite 检查点        │
│    • 行情源：东财直连 → 新浪 → 腾讯 → AkShare 多级降级兜底          │
│    • 本地存储：SQLite 主库 + FTS5 本地知识库（对话、报告、设置）     │
│        │                                                           │
│        │  HTTPS —— 唯一的出网点                                     │
│        ▼                                                           │
│  云端 LLM API —— 你的密钥，你选的厂商                               │
└────────────────────────────────────────────────────────────────────┘
```

你的提问、关注标的与生成的报告永远不出本机。行情数据取自公开接口。
唯一携带你 API Key 的请求，只发往你自己选定的模型厂商。

## 安装

从 [**最新 Release**](https://github.com/lryoooow/Financial-AI-Agent-Platform-/releases/latest) 下载：

| 文件 | 用途 |
| --- | --- |
| `JingYuan-Setup-1.8.1.exe` | 安装包（推荐），创建开始菜单与桌面快捷方式，覆盖安装自动保留本地数据 |
| `JingYuan-Portable-1.8.1.exe` | 便携版，免安装直接运行 |

Windows 10 / 11 x64。无需另装 Python 或 Node，运行时已全部内置打包。

安装包未做商业代码签名，首次运行若遇 Windows SmartScreen 提示，确认来源可信后选择 **更多信息 → 仍要运行**。

## 首次运行

1. 启动景渊，本地研究引擎会自动拉起，默认进入 **深度研究** 任务台。
2. 点击左侧底部 **设置 → 模型服务**，选择一家模型厂商（或自定义兼容端点），粘贴你的 API Key 并选定模型，点击 **设为当前推理模型**。
3. 回到 **深度研究** 生成第一份研报，或前往 **投研问答** 直接提问。

未配置 API Key 时，实时行情、K 线图表、五档盘口与数据源诊断依然正常可用，研报正文自动以本地规则模板生成。

## 本地数据目录

全部位于 `%APPDATA%\FinResearch\`：

- `finresearch.db` —— 对话、报告、模型配置与本地设置
- `knowledge.db` —— 本地知识库（FTS5 全文检索切片）与个性化画像
- `checkpoints.sqlite` —— LangGraph 会话检查点
- `backend.log` / `backend-sidecar.log` —— 运行日志（自动大小轮转）
- `port.txt` —— 后端实际绑定的本地端口

想彻底重置软件，完全退出（右键托盘图标选择「退出」）后删除该文件夹即可；想备份迁移，直接复制该文件夹即可。

API Key 在本地数据库中采用 **Windows 原生 DPAPI 加密存储**，界面与本地接口全程掩码脱敏，仅在实际调用模型时发往你选定的厂商端点。
